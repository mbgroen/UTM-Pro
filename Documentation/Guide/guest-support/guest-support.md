# Guest Support

In order to take full advantage of all the features UTM Pro has to offer, you need to install some software in the virtual machine guest. Currently only [Windows](windows.md) (excluding older versions), [Linux](linux.md), and [macOS](macos.md) have all the drivers and tools to support all of UTM Pro's features. If you run an operating system that is not supported by the guest tools, some of the following features may not work:

* Directory sharing
* Clipboard sharing
* Dynamic screen resolution
* Mouse cursor **macOS** without "capturing" or **iOS** in "tablet mode"
