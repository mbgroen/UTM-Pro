# Version

**macOS**

To find the currently running version, open UTM Pro and in the menu bar, navigate to **UTM Pro → About UTM Pro**. The version and build number will be shown in a new window.

**iOS**

To find the currently installed version, open UTM Pro at least once (after installing the version you wish to find). Then, close UTM Pro and open the system Settings application. Scroll down to the entry for "UTM Pro" and select it. At the end of the preferences, you should see the version and build number.

**WIP** Currently, exploit installed UTM Pro builds do not have the preferences entry.

> [!NOTE]
> If you do not see the version and build number but you do see all the UTM Pro preferences, your version of UTM Pro is too old.
